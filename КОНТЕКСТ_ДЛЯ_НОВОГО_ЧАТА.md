## Предпочтения и устойчивые сведения

- Базу вести самостоятельно для памяти ассистента; пользователь просто задаёт вопросы. Уже переданное сначала искать в базе и учебных чатах, повторно не запрашивать.
- План недели давать коротким списком дел, без расписания пар.
- Пользователь - **вторая подгруппа**, номер фамилии в журнале **22**; для таблицы длинных линий преподаватель назвал **группу 2**.
- Свои ЛР: **сети и машины по нижним неделям, метрология по верхним**. Уточнение пользователя 16.10 важнее сетки без подписей подгрупп.
- Оригиналы не перезаписывать. Фото: один кадр на странице PDF, исходный порядок, номер/имя файла, постраничный индекс. Для точного повтора достаточно ссылки на оригинал и SHA-256.
- Титул обязателен или уместен в объёмной работе — использовать подходящий официальный бланк РГУ нефти и газа имени Губкина; [правило и оригиналы](02_Задания/ОФОРМЛЕНИЕ_РАБОТ.md). Для конкретного предмета приоритет у образца кафедры/преподавателя.
- Объяснения делить на «Для понимания» и «В тетрадь», не пропускать математические переходы. Указывать, куда смотреть: фото/страница, задание, конкретный график. Ток и напряжение - отдельные графики.
- Для допуска по метрологии нужен очень короткий конспект, скрин приборов и таблицы точно как в методичке. Подробный разбор не задавать для переписывания.
- При обучении задавать понятные вопросы для проверки понимания, по 1–2 за раз; разрешено пользователем 06.11. Не считать прочитанное усвоенным без ответа.
- Готовую задачу завершать коротким «Закончил» и ссылкой; без нового поручения не возобновлять.
- Готовый файл не означает проверку, сдачу или загрузку. Чужие показания и примеры не выдавать за личные измерения.
