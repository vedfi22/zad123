## 3. Метод контурных токов

Контурные токи Jа, Jб, Jв направим по трём обходам выше. Тогда:

I1 = Jа − Jб; I2 = Jв − Jб; I3 = Jа − Jв;<br/>I4 = −Jа; I5 = −Jб; I6 = −Jв.

(r1 + R4 + r3)Jа − r1·Jб − r3·Jв = E3 − E1;<br/>−r1·Jа + (r1 + R5 + r2)Jб − r2·Jв = E1 − E2;<br/>−r3·Jа − r2·Jб + (r3 + R6 + r2)Jв = E2 − E3.

5,1Jа − 2,8Jб − 1,3Jв = 36;<br/>−2,8Jа + 7,4Jб − 2,6Jв = −6;<br/>−1,3Jа − 2,6Jб + 10,9Jв = −30.

Сложим три уравнения: внутренние общие ветви сокращаются. Получим уравнение внешнего контура и выразим Jа:

R4·Jа + R5·Jб + R6·Jв = 0;<br/>Jа + 2Jб + 7Jв = 0; Jа = −2Jб − 7Jв.

Подставим его в первые два уравнения системы:

13Jб + 37Jв = −36;<br/>13Jб + 17Jв = −6;<br/>(37 − 17)Jв = −36 − (−6); Jв = −30/20 = −1,5 А.

Jб = (−6 − 17Jв)/13 = [−6 − 17·(−1,5)]/13 = 1,5 А;<br/>Jа = −2Jб − 7Jв = −2·1,5 − 7·(−1,5) = 7,5 А.

Jа = 7,5 А; Jб = 1,5 А; Jв = −1,5 А.

I1 = 7,5 − 1,5 = 6 А; I2 = −1,5 − 1,5 = −3 А;<br/>I3 = 7,5 − (−1,5) = 9 А;<br/>I4 = −7,5 А; I5 = −1,5 А; I6 = −(−1,5) = 1,5 А.

## 11. Метод эквивалентного генератора: все три ветви

В упрощённой схеме удаляем всю рассматриваемую ветвь вместе с её ЭДС и r′. Остальные две ветви заменяем источником U<sub>хх</sub> с сопротивлением R<sub>экв</sub>. Напряжение U<sub>хх</sub> отсчитывается от C к O.

U<sub>хх</sub> = (E<sub>a</sub>/r<sub>a</sub>′ + E<sub>b</sub>/r<sub>b</sub>′)/(1/r<sub>a</sub>′ + 1/r<sub>b</sub>′);<br/>R<sub>экв</sub> = r<sub>a</sub>′r<sub>b</sub>′/(r<sub>a</sub>′ + r<sub>b</sub>′).

Для определения R<sub>экв</sub> оба оставшихся идеальных источника ЭДС закорачиваются. При возврате удалённой активной ветви её собственная ЭДС обязательно входит в уравнение тока.

Ветвь 1: E1, r1′; направление I1 от C к O

U<sub>хх,1</sub> = (E2/r2′ + E3/r3′)/(1/r2′ + 1/r3′)<br/>= (24/4 + 54/2)/(1/4 + 1/2) = 44 В;<br/>R<sub>экв,1</sub> = r2′r3′/(r2′ + r3′) = 4·2/(4 + 2) = 4/3 Ом;<br/>I1 = (U<sub>хх,1</sub> − E1)/(R<sub>экв,1</sub> + r1′)<br/>= (44 − 18)/(4/3 + 3) = <b>6 А</b>.

Ветвь 2: E2, r2′; направление I2 от O к C

U<sub>хх,2</sub> = (E1/r1′ + E3/r3′)/(1/r1′ + 1/r3′)<br/>= (18/3 + 54/2)/(1/3 + 1/2) = 39,6 В;<br/>R<sub>экв,2</sub> = r1′r3′/(r1′ + r3′) = 3·2/(3 + 2) = 1,2 Ом;<br/>I2 = (E2 − U<sub>хх,2</sub>)/(R<sub>экв,2</sub> + r2′)<br/>= (24 − 39,6)/(1,2 + 4) = <b>−3 А</b>.

Ветвь 3: E3, r3′; направление I3 от O к C

U<sub>хх,3</sub> = (E1/r1′ + E2/r2′)/(1/r1′ + 1/r2′)<br/>= (18/3 + 24/4)/(1/3 + 1/4) = 144/7 В;<br/>R<sub>экв,3</sub> = r1′r2′/(r1′ + r2′) = 3·4/(3 + 4) = 12/7 Ом;<br/>I3 = (E3 − U<sub>хх,3</sub>)/(R<sub>экв,3</sub> + r3′)<br/>= (54 − 144/7)/(12/7 + 2) = <b>9 А</b>.

Все три результата совпали с расчётом другими методами. Личная ветвь не назначается по догадке: правило соответствия номеру в журнале в исходнике не дано.

12. Масштабная потенциальная диаграмма


## 12. Масштабная потенциальная диаграмма

Внешний контур исходной схемы: A→F→E→A, то есть R6→R5→R4. В нём нет источников ЭДС, поэтому скачков потенциала нет. Для диаграммы выберем новый нуль φ<sub>A</sub> = 0; разности потенциалов и токи от этого не меняются.

φ<sub>F</sub> = φ<sub>A</sub> + I6·R6 = 0 + 1,5·7 = 10,5 В;<br/>φ<sub>E</sub> = φ<sub>F</sub> + I5·R5 = 10,5 + (−1,5)·2 = 7,5 В;<br/>φ<sub>A,возврат</sub> = φ<sub>E</sub> + I4·R4 = 7,5 + (−7,5)·1 = 0 В.

Абсцисса - накопленная сумма сопротивлений по обходу. При печати в масштабе 100 %: <b>1 Ом = 12 мм; 1 В = 6 мм</b>. Наклоны показывают изменение потенциала на 1 Ом: +1,5; −1,5; −7,5 В/Ом.
