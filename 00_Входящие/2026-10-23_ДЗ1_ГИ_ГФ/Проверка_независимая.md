## 1. Что непосредственно задано источником

На стр. 1 сказано, что цепь содержит три активных элемента. В примечании 2 параметры для других групп предлагается получать, «увеличивая значения активных элементов в соответствии с номером группы». Формула увеличения прямо не дана. Поэтому приведённый ниже результат условен относительно стандартной рабочей интерпретации: ЭДС умножаются на номер группы, сопротивления не меняются.

На схеме №3 первый активный элемент обозначен как U₁ с двумя зажимами, а в таблице соответствующий столбец обозначен E₁. Это один и тот же первый идеальный источник напряжения: E₁ = U₁. Прочерк R₀₁ означает, что внутренний резистор в этой ветви отсутствует; в расчёте идеальному источнику соответствует R₀₁ = 0.

Приборы считаются идеальными: вольтметр и обмотка напряжения ваттметра тока не потребляют, токовая обмотка ваттметра имеет нулевое сопротивление. Иные параметры приборов в источнике не приведены.

## 2. Узлы, ветви и направления источников

Четыре существенных узла расчётной цепи: A, C, E, F. Точки B, D, M — промежуточные точки ветвей и подключения измерительных цепей. Введём дополнительно N — точку между нижним зажимом E₂ и верхним зажимом токовой обмотки ваттметра. Для идеальной токовой обмотки φN = φC.

Шесть ветвей между существенными узлами:

| Ветвь | Порядок элементов по выбранному направлению | Выбранный ток |
|---|---|---|
| C–E | C → R₁ → D → U₁ → E | I₁: C → E |
| F–C | F → R₂ → M → R₀₂ → E₂ → N → токовая обмотка pW → C | I₂: F → C |
| A–C | A → R₀₃ → E₃ → B → R₃ → C | I₃: A → C |
| A–E | A → R₄ → E | I₄: A → E |
| E–F | E → R₅ → F | I₅: E → F |
| F–A | F → R₆ → A | I₆: F → A |

R₄, R₅, R₆ образуют пассивный треугольник A–E–F.

Полярности и направления:

- U₁: знак «+» у D, «−» у E; стрелка напряжения направлена вниз D → E. Поэтому φD − φE = U₁ = 18 В. При проходе C → E источник даёт падение напряжения +U₁.
- E₂: стрелка вниз, от стороны M к N/C; ЭДС повышает потенциал при движении M → C.
- E₃: стрелка вверх, от стороны A к B; ЭДС повышает потенциал при движении A → B.
- pV подключён между M и B. Явные знаки полярности вольтметра на рисунке отсутствуют.

## 3. Обе звёздочки ваттметра

У ваттметра две разные обмотки. Толстая вертикальная линия внутри круга — токовая обмотка, тонкая горизонтальная — обмотка напряжения. Пересечение линий внутри условного обозначения не является обычным соединением проводов.

1. Начало токовой обмотки отмечено верхней звёздочкой, расположенной слева от вертикального входа. Этот зажим обращён к точке N и источнику E₂. Конец токовой обмотки снизу соединён с C.
2. Начало обмотки напряжения отмечено второй звёздочкой, расположенной слева и ниже горизонтального входа в круг. Именно левый горизонтальный зажим тонким проводом соединён с N.
3. Правый горизонтальный зажим обмотки напряжения тонким проводом соединён с M — точкой между R₂ и R₀₂.

Следовательно, оба начала действительно соединены с N. Для принятого I₂, направленного F → C, ток входит в отмеченное начало токовой обмотки, а положительное напряжение обмотки напряжения равно φN − φM. Подписанное показание:

P_W = (φN − φM) I₂ = (φC − φM) I₂.

Напряжение, измеряемое ваттметром, охватывает E₂ и R₀₂, но не R₂. Вторая звёздочка не отмечает нижний токовый зажим C.

## 4. Независимое решение узловым методом

Выбираем φA = 0. Полные сопротивления активных ветвей:

r₁ = R₁ = 2,8 Ом;

r₂ = R₂ + R₀₂ = 2 + 0,6 = 2,6 Ом;

r₃ = R₃ + R₀₃ = 1 + 0,3 = 1,3 Ом.

Токи через узловые потенциалы:

I₁ = (φC − φE − 18) / 2,8;

I₂ = (φF − φC + 24) / 2,6;

I₃ = (54 − φC) / 1,3;

I₄ = −φE / 1;

I₅ = (φE − φF) / 2;

I₆ = φF / 7.

Уравнения первого закона Кирхгофа для C, E, F:

(φC − φE − 18)/2,8 + (φC − φF − 24)/2,6 + (φC − 54)/1,3 = 0;

(φE − φC + 18)/2,8 + φE/1 + (φE − φF)/2 = 0;

(φF − φC + 24)/2,6 + (φF − φE)/2 + φF/7 = 0.

Решение выполнено точной рациональной арифметикой:

φC = 42,3 В; φE = 7,5 В; φF = 10,5 В.

| Ток | Численное значение в принятом направлении | Действительное направление |
|---|---:|---|
| I₁ | +6 А | C → R₁ → D → U₁ → E |
| I₂ | −3 А | C → pW → E₂ → R₀₂ → M → R₂ → F |
| I₃ | +9 А | A → R₀₃ → E₃ → B → R₃ → C |
| I₄ | −7,5 А | E → A через R₄ |
| I₅ | −1,5 А | F → E через R₅ |
| I₆ | +1,5 А | F → A через R₆ |

Промежуточные потенциалы:

φD = φE + U₁ = 7,5 + 18 = 25,5 В;

φM = φF − R₂I₂ = 10,5 − 2·(−3) = 16,5 В;

φB = φA − R₀₃I₃ + E₃ = 0 − 0,3·9 + 54 = 51,3 В;

φN = φC = 42,3 В.

## 5. Показания приборов

Вольтметр:

U_BM = φB − φM = 51,3 − 16,5 = +34,8 В.

Так как на рисунке не обозначена полярность его зажимов, однозначное показание по модулю равно 34,8 В. При условном измерении U_MB знак был бы отрицательным: −34,8 В. Точка B имеет больший потенциал.

Напряжение обмотки ваттметра от отмеченного начала:

U_W = φN − φM = 42,3 − 16,5 = 25,8 В.

То же через реальные зажимы второго источника:

U_W = E₂ − R₀₂I₂ = 24 − 0,6·(−3) = 25,8 В.

Ток, отсчитанный во входящем в отмеченное начало направлении, I_W = I₂ = −3 А. Поэтому:

**P_W = U_W I_W = 25,8·(−3) = −77,4 Вт.**

Знак существенен: фактический ток идёт снизу вверх и входит в неотмеченный конец токовой обмотки. Второй активный элемент вместе с R₀₂ потребляет 77,4 Вт; ваттметр подключён для положительного отсчёта отдаваемой этим элементом мощности. Величина 77,4 Вт включает 72 Вт, поглощаемые идеальной ЭДС E₂, и 5,4 Вт потерь в R₀₂.

## 6. Проверки

Первый закон Кирхгофа:

- C: I₁ − I₂ − I₃ = 6 − (−3) − 9 = 0;
- E: I₁ + I₄ − I₅ = 6 − 7,5 − (−1,5) = 0;
- F: I₅ − I₂ − I₆ = −1,5 − (−3) − 1,5 = 0;
- A: I₆ − I₃ − I₄ = 1,5 − 9 − (−7,5) = 0.

Все шесть ветвевых уравнений согласуются с потенциалами:

- C–E: 2,8·6 + 18 = 34,8 = φC − φE;
- F–C: 2,6·(−3) − 24 = −31,8 = φF − φC;
- A–C: 1,3·9 − 54 = −42,3 = φA − φC;
- A–E: 1·(−7,5) = −7,5 = φA − φE;
- E–F: 2·(−1,5) = −3 = φE − φF;
- F–A: 7·1,5 = 10,5 = φF − φA.

Мощность, выделяемая во всех сопротивлениях:

P_R = 2,8·6² + 2,6·3² + 1,3·9² + 1·7,5² + 2·1,5² + 7·1,5²

= 100,8 + 23,4 + 105,3 + 56,25 + 4,5 + 15,75 = 306 Вт.

Алгебраическая мощность, отдаваемая идеальными источниками:

P_ист = −U₁I₁ + E₂I₂ + E₃I₃

= −18·6 + 24·(−3) + 54·9 = −108 − 72 + 486 = 306 Вт.

E₃ работает генератором, E₂ и U₁ потребляют энергию. Баланс сходится без остатка. Он также записывается как 486 = 306 + 108 + 72 Вт.

## Заключение проверки

При рабочем допущении 3×ЭДС и неизменных сопротивлениях схема однозначно даёт токи 6 А, 3 А, 9 А в активных ветвях, 7,5 А, 1,5 А, 1,5 А в пассивном треугольнике с указанными выше направлениями. Вольтметр показывает по модулю 34,8 В, ваттметр с нарисованными звёздочками — **−77,4 Вт**. Единственная не снятая исходником организационная неоднозначность — точная формула изменения ЭДС по номеру группы; выбранное правило явно обозначено как допущение.
