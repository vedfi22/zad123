## Токи и контуры, которые следует сохранить

| Ток | Условное положительное направление в исходной и восстановленной цепи | Значение, А |
|---|---|---:|
| I1 | C → E, через R1 и U1 | 6 |
| I2 | F → C, через R2, R02 и E2 | -3 |
| I3 | A → C, через R03, E3 и R3 | 9 |
| I4 | A → E, через R4 | -7,5 |
| I5 | E → F, через R5 | -1,5 |
| I6 | F → A, через R6 | 1,5 |

Отрицательный результат не требует переворачивать условную стрелку в расчётной схеме. Фактические направления отдельно: I2 идёт C → F, I4 идёт E → A, I5 идёт F → E.

Обходы: Jа: C → E → A → C; Jб: C → F → E → C; Jв: C → A → F → C. Соответственно:

```text
I1 = Jа - Jб;  I2 = Jв - Jб;  I3 = Jа - Jв;
I4 = -Jа;     I5 = -Jб;      I6 = -Jв.

 5,1 Jа - 2,8 Jб -  1,3 Jв =  36;
-2,8 Jа + 7,4 Jб -  2,6 Jв =  -6;
-1,3 Jа - 2,6 Jб + 10,9 Jв = -30.

Jа = 7,5 А; Jб = 1,5 А; Jв = -1,5 А.
```

Здесь r1=2,8 Ом, r2=R2+R02=2,6 Ом, r3=R3+R03=1,3 Ом. Правые части: E3-E1=36 В, E1-E2=-6 В, E2-E3=-30 В. Матрица и токи заново получены через связи ветвей и контуров; отдельно решены узловые уравнения исходной цепи. Результаты совпали точно, с рациональной арифметикой.

## Треугольник → звезда → треугольник

Исходные стороны: R4 между A и E, R5 между E и F, R6 между F и A. Центр новой звезды обозначить O. Сумма S=R4+R5+R6=1+2+7=10 Ом.

```text
RA (A-O) = R4·R6/S = 1·7/10 = 0,7 Ом;
RE (E-O) = R4·R5/S = 1·2/10 = 0,2 Ом;
RF (F-O) = R5·R6/S = 2·7/10 = 1,4 Ом.
```

На промежуточном рисунке сохранить точки A, E, F и показать именно эти три соединения. После последовательного объединения получаются три ветви между C и O:

```text
r1' = R1 + RE = 3 Ом;
r2' = R2 + R02 + RF = 4 Ом;
r3' = R3 + R03 + RA = 2 Ом.

UCO = (18/3 + 24/4 + 54/2)/(1/3 + 1/4 + 1/2) = 36 В;
I1 = (36-18)/3 = 6 А;
I2 = (24-36)/4 = -3 А;
I3 = (54-36)/2 = 9 А.
```

В звезде условные направления: по RE ток I1 идёт E → O; по RF ток I2 идёт O → F; по RA ток I3 идёт O → A. Токи I4/I5/I6 относятся к удалённым сторонам треугольника, а не к плечам звезды.

Для обратного преобразования нужна **полная сумма трёх попарных произведений**:

```text
P = RA·RE + RE·RF + RF·RA
  = 0,7·0,2 + 0,2·1,4 + 1,4·0,7
  = 0,14 + 0,28 + 0,98 = 1,4 Ом².

R4 (A-E) = P/RF = 1,4/1,4 = 1 Ом;
R5 (E-F) = P/RA = 1,4/0,7 = 2 Ом;
R6 (F-A) = P/RE = 1,4/0,2 = 7 Ом.
```

Возвращаются исходные сопротивления и их пары узлов. При φE=0 расчёт звезды даёт φA=-7,5 В, φF=3 В; поэтому после возврата:

```text
I4 = (φA-φE)/R4 = -7,5/1 = -7,5 А;
I5 = (φE-φF)/R5 = -3/2 = -1,5 А;
I6 = (φF-φA)/R6 = 10,5/7 = 1,5 А.
```

## Указание для новых рисунков

На исходном и восстановленном треугольнике подписать одинаковые узлы, I1-I6 и обходы Jа/Jб/Jв из таблицы и формул выше. В промежуточной звезде показать сохранение I1-I3 и принадлежность плеч узлам. После замены треугольника звездой остаются **два независимых контура**: прежние три обхода, продолженные через O, становятся линейно зависимыми. Трёхконтурную матрицу исходной цепи нельзя приписывать схеме звезды.
