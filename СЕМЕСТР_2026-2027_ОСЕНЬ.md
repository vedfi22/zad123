# Рабочая модель семестра

Сверено 16.10.2026. В базе **11 дисциплин** и отдельный раздел практики. Эта запись хранит состав работ и границы уверенности для ассистента. Даты, сдача и оценки — только в [АКТУАЛЬНО](АКТУАЛЬНО.md); ближайшие учебные действия — в README предметов через [карту](../КАРТА_МАТЕРИАЛОВ.md).

## Состав программы

Основа старого рейтинга — [выгрузка 03.09](../УСПЕВАЕМОСТЬ_2026-09-03.md), раздел соответствующей дисциплины. Это первоначальный ориентир, который уточняется свежими условиями и сообщениями пользователя.

| Предмет | Рабочий состав и ограничение |
|---|---|
| Культура научного мышления | Два ДЗ, два семинара, итоговая КР; исходный рейтинг на 100 баллов. ДЗ №2 включает ответ по Платону и отдельное эссе. Выступления Фарадей/Поппер не заменяют это эссе. |
| Метрология | Три лабораторные и одна КР, по 15 баллов, всего 60. ЛР №2 и №3 имеют разные комплекты материалов. Не путать конспект допуска, обработку измерений и защиту. |
| Силовая электроника | Пользователь считает основной программой четыре ДЗ на 100 баллов; исторический рейтинг даёт четыре работы по 25. Связь семинара №1 с ДЗ №1/КР №1 не установлена. Дополнительные тесты и бонусный реферат автоматически не назначать. Новое ДЗ №3 — повышающий преобразователь; №4 — триггер Шмитта. |
| Социальное взаимодействие | Есть текущие условия двух ДЗ и карточки двух КР; отдельно записан личный доклад. Исторический рейтинг на 100 баллов включает также активность. Точное соответствие старых рейтинговых названий новым карточкам и связь доклада с ДЗ №2 не установлены. |
| ТАУ | Старый рейтинг перечисляет три КР, три РГР, семинарскую активность и бонус. Свежая переданная страница edu не содержит условий. Эти строки рейтинга и старые книги не создают личное задание. |
| Теория поля | Исходный рейтинг: четыре КР по 15 и индивидуальное ДЗ по длинным линиям на 40, всего 100. Описание нынешнего ДЗ подтверждает максимум 40. Отдельные лекционные упражнения и новая задача №2 не тождественны этому ДЗ. |
| Физкультура | Личное ограничение пользователя: состоит в сборной, учитывать только текущий тест №2. Стандартные нормативы и посещаемость из старого рейтинга в его план автоматически не переносить. |
| Экономика | Свежий рейтинг: три КР (15/20/15), два ДЗ (10/15), тест (10), активная работа (15), всего 100. Опубликованные условия и написанная в аудитории работа — разные основания; «не проверена» не означает «не выполнена». |
| Электрические аппараты | Текущая страница edu без условий; рейтингового состава в исходной выгрузке нет. Полное пособие содержит одну комплексную лабораторную из четырёх частей. Личный состав опытов и число работ за семестр требуют уточнения. |
| Электрические машины | В старом рейтинге четыре ЛР и четыре КР на 60 баллов. Полная новая методичка содержит 11 работ, но программа пользователя сокращённая. Сопоставлять темы и опыты, не назначать все 11 и не полагаться только на номер «ЛР №2». |
| Электрические сети | Старый рейтинг — 11 позиций на 60 баллов; в свежем перечне edu видны семь элементов. Не объявлять отсутствующие старые работы уже назначенными. Текущая ЛР №2 на портале соотносится с работой №4 в новом PDF; альтернативная №5 не выбрана пользователем. |

## Как продолжать работу

- При общем вопросе о делах читать АКТУАЛЬНО и действующий недельный план; при предметном — README и нужный индекс. По материалам давать источник и точную страницу/кадр.
- В других учебных чатах уже подготовлены результаты. Сначала проверять общие файлы и [запись сверки чатов](01_Исходники/2026-10-16_Сверка_учебных_чатов.md), чтобы не повторять сделанное. Старые просьбы и оборванные ходы не запускать заново автоматически.
- Личные измерения, чужие примеры и методические условия имеют разное происхождение. Вариант 22 — номер пользователя; исключения и номера таблиц подтверждать отдельно.
- При новом сообщении обновлять соответствующую предметную запись и единственный список статусов. Не копировать подробную историю в контекст, карту и README одновременно.
- По ТАУ и новым экономическим работам ждать условий преподавателя. Неделя рейтинга не устанавливает точную дату выдачи или сдачи.

[Личное уточнение пользователя о самостоятельном ведении базы](01_Исходники/2026-10-16_Режим_ведения_базы.md). Оформление служит поиску ассистента; пользователь может просто задавать вопросы.
