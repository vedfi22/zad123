## Метрология: опора для тренировки

Источники в учебной базе: методичка ЛР №1, **PDF стр. 4–5** (погрешности и класс), **11–13** (делитель и вопросы); методичка ЛР №2, **PDF стр. 2–3** (систематическая составляющая), **6–7** (нагрузка вольтметром и схема), **12** (вопросы). Полный проверенный разбор: `01_Предметы/Метрология_и_измерительная_техника/02_Конспекты/2026-11-06_КР1_Порядок_повторения_и_3_примера.md`.

Обозначения и формулы:

- Знаковая погрешность: Δx = x − x₀. Положительная граница: |Δx| ≤ d. Относительная погрешность: δ = Δx / x₀ × 100 %. Приведённая: γ = Δx / xN × 100 %.
- Для класса K, заданного по приведённой погрешности: dU = K × UN / 100; относительная **граница** по показанию εU ≈ dU / |U| × 100 %. Знак фактической погрешности класс не даёт.
- Поправка к оценённой систематической погрешности: Π = −Δxсист, исправленный результат xи = x + Π.
- Нагрузка вольтметром: Ux = U₀ × Rвх / (Rвн + Rвх); Π = Ux × Rвн / Rвх.
- Косвенное измерение: D = Uвх / Uвых; при небольших предельных границах dD / |D| ≈ dвх / |Uвх| + dвых / |Uвых|.

Три уже разобранных **учебных** примера, на которых можно строить новые варианты:

1. K = 0,5; шкала 0–50 В; показание 35 В. Граница dU = 0,5 × 50 / 100 = 0,25 В; относительная граница ≈ 0,25 / 35 × 100 % = 0,71 %. Итог: **(35,00 ± 0,25) В**. При показании 5 В на том же диапазоне абсолютная граница та же, относительная — 5 %.
2. ЭДС 10 В, Rвн = 1 кОм, Rвх = 9 кОм. Вольтметр покажет 10 × 9 / (1 + 9) = **9 В**. Методическая погрешность относительно ЭДС = −1 В, поправка = +1 В. Это идеализированная модель; общая граница прибора не задана.
3. Uвх = (20,00 ± 0,10) В, Uвых = (2,000 ± 0,020) В. D = 10; приближённая граница ≈ 0,15. Проверка крайних отношений даёт максимум около 0,151515, поэтому округлённая вверх строгая граница **0,16**, итог **D = 10,00 ± 0,16** без единицы измерения.

Порядок оформления ответа: **формула → подстановка с единицами → промежуточный результат → обоснованная граница → согласованный разряд**. Начать тренировку с различия между знаковой погрешностью Δ и положительной границей d, затем дать похожую задачу на класс прибора без готового решения.
